# 🐉 Драконья математика

Тренажёр по математике за 4 класс (программа Петерсон) для Тихона.
Всё приложение — один файл `index.html`: без установки и без интернета.

## Как запустить
**Вариант 1 (проще всего):** откройте `index.html` двойным кликом. Лучше всего в Chrome или Edge.

**Вариант 2 (через локальный сервер):**
```bash
cd argame
python3 -m http.server 8000
# откройте http://localhost:8000
```
Важно: прогресс хранится в браузере отдельно для каждого способа открытия
(file:// и http://localhost — это разные «адреса»). Выберите один способ и открывайте приложение всегда им.

## Перенос на другой компьютер
**1. Скопировать игру.** Нужен только файл `index.html`. Варианты:
- скачать с GitHub: https://github.com/AlexanderKomarovProwidelabs/dragonmath → зелёная кнопка **Code → Download ZIP**, распаковать;
- или скопировать `index.html` на флешку;
- или, если стоит git: `git clone https://github.com/AlexanderKomarovProwidelabs/dragonmath.git`.

Положите файл в постоянную папку (например, `Документы\Математика`) и больше его не перемещайте:
прогресс привязан к адресу файла, после перемещения браузер начнёт «с нуля».

**2. Открыть в правильном браузере.** Правый клик по `index.html` → «Открыть с помощью» → Chrome, Edge или Firefox.
Internet Explorer не подойдёт. На Windows 7 нужен Chrome 109 или Firefox 115 ESR (последние версии для Windows 7).
Удобно сделать ярлык на рабочем столе: правый клик по файлу → «Отправить» → «Рабочий стол (создать ярлык)».

**3. Перенести прогресс** (если дети уже занимались на старом компьютере).
На старом компьютере: «Родителям» → вкладка ребёнка → «Сохранить прогресс в файл». Повторить для второй вкладки.
Получится два файла `drakon-matematika-tikhon-….json` и `drakon-matematika-anisia-….json` — перенесите их на флешке.
На новом компьютере: открыть игру → «Родителям» → вкладка ребёнка → «Загрузить из файла» → выбрать его файл.
Важно загружать файл во вкладку того же ребёнка.

**4. Заново задать PIN.** PIN в файл прогресса не попадает: «Родителям» → вкладка ребёнка → «Задать PIN».

**5. Проверить голос.** «Родителям» → «Проверить голос». На Windows 7 своего русского голоса нет;
Chrome использует голос Google, которому нужен интернет. Без интернета игра работает, но без озвучки.

## Что внутри
- Два профиля: Тихон (дракон) и Анисия (фея). При запуске — экран «Кто играет?». У каждого свой прогресс,
  настройки и PIN из 4 цифр. PIN задаётся и убирается в панели родителя (вкладка нужного ребёнка).
  PIN защищает только от входа в чужой профиль: всё хранится в браузере.
- **Анисия (фея), дошкольная математика по Петерсону, числа до 10:** 11 островов «Волшебного сада» и финал «Прогони тучу»:
  сколько? → собери в корзинку (перетаскивание мышью) → цифры → числа по порядку → больше/меньше/поровну →
  домики чисел (состав числа) → сложение и вычитание на картинках → фигуры → что дальше? (закономерности) → где? какой по счёту?
  Задания читаются вслух автоматически, ответы — выбор картинки или числа. Уровни: до 5, до 7, до 10. Раунд — 6 задач, перерыв каждые 7 минут.
- **Тихон (дракон), 4 класс:** 19 островов от простого к сложному: таблица → круглые числа → 2-значное×1-значное → деление → остаток →
  2-значное×2-значное → деление подбором → текстовые задачи → доли → дроби → смешанные числа → финальная битва.
- Следующий остров открывается после 2 звёзд на предыдущем. В панели родителя можно открыть все острова сразу.
- Уровень сложности подстраивается сам: 3 верных ответа подряд — сложнее, 2 ошибки подряд — проще.
- После ошибки трудную задачу можно решить по шагам. После второй ошибки показывается решение, а похожая задача добавляется в конец раунда.
- Каждые 10 минут — двигательная пауза. Интервал настраивается.
- Дракон и фея растут от правильных ответов. За кристаллы им покупают вещи (у каждого около 45): цвет, узор, шапки,
  очки, украшения на шею, крылья, суперсилу, питомца и фон. Три вещи у каждого — только награды:
  дракону за победу над троллем, 3 звезды на всех Огненных островах и 3 звезды на 10 островах;
  фее — за то, что прогнала тучу, 3 звезды на всей Цветочной поляне и 3 звезды на 8 островах.
- Панель родителя (кнопка «Родителям», вход по примеру): время занятий, точность по темам, частые ошибки, настройки, сохранение прогресса в файл и загрузка из файла.

## Озвучка
Используется встроенный голос браузера. Если кнопка 🔊 молчит, значит, в системе нет русского голоса:
- Windows: «Параметры → Время и язык → Речь» → добавить русский голос;
- Linux: `sudo apt install speech-dispatcher espeak-ng` (голос будет роботизированный); в Chrome на Linux русские голоса Google обычно работают только при подключённом интернете.
Проверить голос можно в панели родителя.
