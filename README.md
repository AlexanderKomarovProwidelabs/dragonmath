# 🐉 Драконья математика

Тренажёр по математике за 4 класс (программа Петерсон) для Тихона.
Всё приложение — один файл `index.html`: без установки и без интернета.

## Как запустить
**Вариант 1 (проще всего):** откройте `index.html` двойным кликом. Лучше всего в Chrome или Edge.

**Вариант 2 (через локальный сервер):**
```bash
cd argame
python3 -m http.server 8000
# откройте http://localhost:8000
```
Важно: прогресс хранится в браузере отдельно для каждого способа открытия
(file:// и http://localhost — это разные «адреса»). Выберите один способ и открывайте приложение всегда им.

## Что внутри
- Два профиля: Тихон (дракон) и Анисия (фея). При запуске — экран «Кто играет?». У каждого свой прогресс,
  настройки и PIN из 4 цифр. PIN задаётся и убирается в панели родителя (вкладка нужного ребёнка).
  PIN защищает только от входа в чужой профиль: всё хранится в браузере.
- 19 островов от простого к сложному: таблица → круглые числа → 2-значное×1-значное → деление → остаток →
  2-значное×2-значное → деление подбором → текстовые задачи → доли → дроби → смешанные числа → финальная битва.
- Следующий остров открывается после 2 звёзд на предыдущем. В панели родителя можно открыть все острова сразу.
- Уровень сложности подстраивается сам: 3 верных ответа подряд — сложнее, 2 ошибки подряд — проще.
- После ошибки трудную задачу можно решить по шагам. После второй ошибки показывается решение, а похожая задача добавляется в конец раунда.
- Каждые 10 минут — двигательная пауза. Интервал настраивается.
- Дракон растёт от правильных ответов. За кристаллы можно купить ему аксессуары.
- Панель родителя (кнопка «Родителям», вход по примеру): время занятий, точность по темам, частые ошибки, настройки, сохранение прогресса в файл и загрузка из файла.

## Озвучка
Используется встроенный голос браузера. Если кнопка 🔊 молчит, значит, в системе нет русского голоса:
- Windows: «Параметры → Время и язык → Речь» → добавить русский голос;
- Linux: `sudo apt install speech-dispatcher espeak-ng` (голос будет роботизированный); в Chrome на Linux русские голоса Google обычно работают только при подключённом интернете.
Проверить голос можно в панели родителя.
